Base: merged #58 at `6fefa040accdeff76a318c693de9fe6043f585eb`.

Parent #17 remains open; this is native data-format support, not semantic parity.

Format source: [JVMS Java SE 23 §4.7.9–4.7.9.1](https://docs.oracle.com/javase/specs/jvms/se23/html/jvms-4.html#jvms-4.7.9).
Independent implementation, no upstream parser code copied. Signature context
selects class, method or field grammar with exact complete consumption. A field
is a reference (class, variable, array); a method permits primitive parameters
and result, void result, formal parameters and class/variable throws. A class
has optional formal parameters, one class superclass and class interfaces.
Formal parameters preserve optional class bounds and repeated interface bounds;
a missing class bound is grammatical, including before parameters named Long/T.
Class types preserve slash-delimited packages, dot-delimited owner segments and
per-segment argument lists. Arguments preserve exact/extends/super/star variance.
Argument/formal lists must be nonempty when present. Identifier names are nonempty
lossless UTF-16 slices excluding exactly `. ; [ / < > :`, not Java source names.
Consecutive array dimensions are flattened; no recursive array AST/drop chain.

Public `parse_signature[_with_limits]` takes UTF-16 and explicit `Context`.
`decode_signatures[_with_limits]` borrows a frozen `ClassFile` and returns class,
field and method results aligned with original member order. Each recognized
attribute must be unique within its owner table and contain exactly two bytes
pointing to a nonzero typed UTF8 CP entry. Attribute-name indices are likewise
checked, including ignored attributes. Forged public model index zero, wrong tags,
missing slots and unsupported versions return errors. Supported base version
range is unchanged; recognized Signature attributes require major 49 or later.
Raw attributes and the base parser remain unchanged.

Hard whole-operation caps (caller `Limits` can only reduce them): 8 MiB charged
bytes, 65,535 AST nodes, 65,535 visited records, 16 Mi work units, depth 32.
Bytes include **all** visited raw attribute payloads plus two bytes per parsed
UTF-16 unit, including repeated references. Records count class, each field/method
and every visited attribute, including absent/ignored signature owners. Nodes
count signature roots, types, identifier/package slices, class segments, formal
parameters and type arguments before allocation. Work charges every parsed UTF-16
unit and every referenced attribute-name unit, plus optional-bound lookahead
units. Budgets never reset between members/attributes/shared CP references.
Checked subtraction/multiplication rejects overflow. No reserve derives from
untrusted collection sizes. Recursive type descent checks depth before work;
partial output/drop is bounded by the same cap. Consecutive array dimension cap
is 255. Wide lists are iterative and node/record bounded.

Residual limits: no erasure/descriptor agreement, duplicate formal-variable
semantic checks, scope/linkage/bound-kind resolution or JVM verification.
Constructors may legitimately have different signature/descriptor argument counts.
Record components, Code/local-variable attribute interiors and annotations/nesting
are separate children. No official LSP differential comparison or JVM ran here.
