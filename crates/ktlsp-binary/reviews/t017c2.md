# T017c2 / #69 contract and delivery evidence

Child of #17, depending on merged #58. Scope is JVMS Java SE 23 §4.7.16–17 declaration RuntimeVisibleAnnotations/RuntimeInvisibleAnnotations on class/field/method only: <https://docs.oracle.com/javase/specs/jvms/se23/html/jvms-4.html#jvms-4.7.16>. Parent #17 stays open. Parameter/type annotations and AnnotationDefault remain #71; record components, Code interiors, semantic type resolution, annotation linkage and Kotlin metadata interpretation are not delivered.

The frozen consumer interface (after merge) is `annotations::decode(&ClassFile) -> Result<DeclarationAnnotations, Error>`. Output has explicitly separate `class`, `fields` and `methods`; ordered member vectors include empty entries. Each AnnotationAttribute retains visibility and annotation order; each Annotation retains the exact UTF-16 descriptor and ordered Element names/values. Value distinguishes all primitive tags, numeric CP bits, direct Utf8 strings, enum descriptor/name, class descriptor (including V), nested annotations and arrays. UTF-16 units are borrowed from the input CP, including NUL/unpaired surrogates. No lossy string conversion, semantic inference, new dependency, Cargo/lock change, or server capability. Raw attributes/CP indices remain available unchanged in the ClassFile.

One whole-call aggregate budget is pinned: 16 MiB of all visited raw attribute payloads (including ignored attributes); 65,535 member/attribute/annotation/pair/value nodes; 64 Mi work units (one per CP reference, referenced UTF-16 unit and possible duplicate-name comparison unit). Counts are charged before loops/output growth. Duplicate element names compare content even across distinct CP slots; the simple bounded pairwise check can exhaust work for very large annotations with many long/shared-prefix names. Names/descriptors are validated with the existing reader helpers under local zero-index/work guards. Hard depth 64 counts each annotation and element_value, with the root annotation at 1; checked before descent. This bounds decode and output drop recursion. Oversized counts, repeated references/attributes/members and duplicate comparisons share the budget. Public forged structures are safe at consumed boundaries; this module does not reverify unrelated CP/class structure. Version policy preserves parse_class's Java23/67.0 ceiling and requires 49.0 for recognized annotations.

Tests are independently authored Rust byte builders and a precompiled data-only Kotlin corpus. Every tag/constant compatibility, descriptor forms, direct UTF16 preservation, visibility/context/order/raw preservation, duplicate names/attributes, malformed tags/indices, every-byte truncation, trailing bytes, version/aggregate resource/depth limits and deterministic mutations are exercised. `fixtures/t017c2/provenance.json` records source coordinates, jar/class SHA256, manifest distribution version and compiler-provenance limits. Classes are copied unmodified from an existing kotlin-stdlib 2.3.20 JAR; LICENSE/NOTICE accompany them. No javac, JVM, Gradle, Maven or oracle was executed. Text notices originate from the Kotlin v2.3.20 repository's `license/LICENSE.txt` and `license/NOTICE.txt`.

Architect reviewed plan before implementation: requested bounded container traversal, charged duplicate comparisons, zero-index and special-name guards, lossless integer bits, and one whole-class API. All incorporated. Independent correctness/adversarial reviews and validation are recorded below.
