# ktlsp

A Rust-only Kotlin language server under development. The goal is feature parity with the official Kotlin language server; parity has **not** been achieved.

The implementation and its build must not require a JVM, JDK, Kotlin compiler, JNI, or C/C++ parser. Kotlin/JVM dependency artifacts can be read as data.

Research, specifications, acceptance criteria, and delivery status live in `docs/`. Unsupported language and project behavior must remain explicit.
